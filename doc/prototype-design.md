# 终端优先原型与接入约束

## 已确认

- Electron 路线；原生 Pi TUI 为中心，旁边提供辅助面板。
- 不能以牺牲 Pi 能力换取图形化；支持中转站 API Key 与便捷模型选择。
- Pi 上游 LICENSE 已读取：MIT，Copyright (c) 2025 Mario Zechner。复用须保留版权及许可声明。当前未复制 Pi 或候选客户端源码。

## 视觉与交互

石墨背景 #111517，辅助面板 #191f22，正文 #e9efed，辅助文字 #a7b5b4，青绿色强调 #a4e6cc。系统无衬线正文、等宽命令文字，无远程字体或素材依赖。
三栏桌面：项目导航、主终端、辅助面板；中屏隐藏左导航；窄屏将辅助面板放在终端下方。44px 最小按钮、可见键盘焦点、原生对话框、键盘可切换标签和减少动画支持。

## 原型行为

`prototype/index.html` 可直接打开，无后端和外部请求。模型配置仅存当前页面内存，刷新即清除。模型选择只产生待应用状态；没有启动 Pi、PTY 或发送模型请求。
模型配置导出为 `pi-models-draft.json`，仅包含环境变量引用。不会收集真实 Key，不会覆盖原生配置。只实现常用协议与保守的模型 ID 校验，未知协议和字符需后续核验，不代表 Pi 本身不支持。
命令按钮只暂存 `/model`、`/thinking`、`/scoped-models`，可手动复制，不自动向终端输入。

## 正式实现约束

1. 真实 Pi 通过 PTY 执行，不用 RPC 聊天替代 TUI。辅助能力使用可选扩展桥，不能解析 ANSI 输出猜测运行状态。
2. 快速切换模型保留 Pi 原生入口；图形操作经运行时确认后才显示成功。不向有未提交输入的终端直接塞命令。
3. 中转 API 类型、路径和模型 ID 以供应商实际契约为准。正式版密钥在可信后端处理，不写日志、源码或导出文件。
4. 配置写入先读取和合并，保留未知字段、校验冲突；原型导出文件不可直接覆盖现有 models.json。
5. 中文输入、快捷键、终端尺寸、图片、扩展和退出清理需要真实运行测试。原型浏览器测试不能代替这些验证。

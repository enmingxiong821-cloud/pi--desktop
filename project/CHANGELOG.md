# 变更记录

本项目遵循语义化版本。日期均为北京时间。

## [1.5.0] - 2026-10-18

### 新增

- 配置共享套件：项目配置导出 / 导入、配置模板（最多 20 个）、从 `.env` 批量导入环境变量、重置项目配置。
- 终端输入区新增项目 / 模型 / 项目工具上下文条，以及「继续上次」「解释项目」「修复报错」「总结改动」快捷指令；快捷指令只填入输入框，确认后按 Enter 才会发送。
- 项目配置中的环境变量支持逐行显示 / 隐藏。

### 调整

- 「项目工具」从左侧栏底部移到顶部导航，与项目、模型等入口并列，成为独立页面。
- 项目工具页占满左侧栏高度，内部面板独立滚动；折叠行为保留。
- 启动阶段的市场、Agent 与可视化探测延后，避免与首屏和终端争抢 CPU。
- 环境探测、应用扫描与外部工具检测改为异步执行并增加缓存；`catalog`、`agents`、`tools` 等 IPC 不再阻塞主进程。

### 安全

- 导出的项目配置与模板只包含模型、推理度与启动方式，永不包含环境变量值。
- 导入配置时忽略环境变量字段；`.env` 导入按行合并，超出变量上限时拒绝写入。

### 修复

- 启动时主进程同步探测造成的界面卡顿与事件循环停顿。

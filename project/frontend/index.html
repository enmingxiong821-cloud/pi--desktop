          最近会话
          
        

        

        

          省 Token 做法
          
    
            
  • 先用大分类收窄 Skills / MCP，再把具体能力装进当前项目，只加载需要的说明。
    • 
            
  • 探索代码先看项目结构和局部文件，避免把整个仓库读入上下文。
    • 
            
  • 长会话接近上下文上限时新开会话并附上结论摘要，保留最近文件与未解问题。
    • 
            
  • 同一会话内尽量不切换模型或推理度，避免 prompt cache 失效。
    • 
            
  • 检索、总结、批量命名交给低价模型，难题再升级到旗舰模型。
